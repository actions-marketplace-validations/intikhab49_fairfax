Microsoft government cloud feature availability

One table per service for GCC, GCC High, DoD and Azure Government, built from Microsoft's own availability pages: 633 features across Azure, Power Platform and Microsoft 365, 8 cross-cloud rules and 57 endpoint mappings. Every row quotes Microsoft, links to the page and carries two dates: when Microsoft last updated the page and when fairfax last checked it.

Every Monday a workflow runs fairfax verify, which re-reads each of these pages and confirms that every row and quote fairfax cites is still there, word for word. If Microsoft changes one, the workflow opens an issue that shows the cited text next to what the page says now; if a page is gone, the issue says so too. Each page also has a Wayback Machine snapshot that was checked to hold the same rows, so a citation can still be checked after Microsoft moves or deletes the page. You can run the same checks yourself: fairfax verify and fairfax verify --archived.

Download the data

The dataset is plain YAML in the repository, MIT licensed: azure-ai.yaml, azure-ml.yaml, defender-for-cloud.yaml, defender.yaml, endpoints-defender.yaml, endpoints.yaml, errors.yaml, exchange.yaml, intune.yaml, m365-copilot.yaml, power-platform.yaml, purview.yaml, roadmap.yaml, rules.yaml, sentinel.yaml, sharepoint.yaml, sources-m365.yaml, sources.yaml, teams.yaml. Or from the command line: fairfax facts --format json.
