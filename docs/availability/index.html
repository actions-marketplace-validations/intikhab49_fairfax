Microsoft government cloud feature availability

One table per service for GCC, GCC High, DoD and Azure Government, built from Microsoft's own availability pages: 187 features, 8 cross-cloud rules and 55 endpoint mappings. Every row quotes Microsoft, links to the page and carries two dates: when Microsoft last updated the page and when fairfax last checked it.

Download the data

The dataset is plain YAML in the repository, MIT licensed: azure-ai.yaml, azure-ml.yaml, defender-for-cloud.yaml, endpoints.yaml, power-platform.yaml, rules.yaml, sentinel.yaml, sources.yaml. Or from the command line: fairfax facts --format json.
