On Microsoft's 365 roadmap

How to read these tables

  • GA and Available: Microsoft lists it as available.
  • Preview, Private preview, Limited, Rolling out: available with conditions, or on its way.
  • Not available, No plans, Planned, In development, On engineering backlog: you can't use it there today. These are Microsoft's own words. A planned date that has passed is marked, so you re-check it.
  • Not possible: Microsoft says that pairing of clouds can't work.
  • not listed: Microsoft's page doesn't give a status for that cloud.

A feature missing from this page tells you nothing about whether it works. fairfax only knows what is in its dataset.
