On Microsoft's 365 roadmap

Roadmap items linked by hand to features above that are missing in a cloud. fairfax check shows them on blocked findings.

  • m365-copilot/declarative-agents: roadmap 564606, “Microsoft Copilot (Microsoft 365): Declarative agents with Actions available in GCC High and DoD”, Launched for GCC High, DoD, target 2026-06.
  • m365-copilot/edit-in-office-apps: roadmap 542181, “Microsoft Copilot (Microsoft 365): Edit with Copilot in Excel (Web, Win32, Mac) - GCC”, In development for GCC, GCC High, DoD, target 2026-10.
  • m365-copilot/copilot-analytics: roadmap 570428, “Microsoft Viva: Viva Insights and Copilot Analytics in GCC-High”, In development for GCC High, target 2026-09 (that month has passed).

How to read these tables

  • GA and Available: Microsoft lists it as available.
  • Preview, Private preview, Limited, Rolling out: available with conditions, or on its way.
  • Not available, No plans, Planned, In development, On engineering backlog: you can't use it there today. These are Microsoft's own words. A planned date that has passed is marked, so you re-check it.
  • Not possible: Microsoft says that pairing of clouds can't work.
  • not listed: Microsoft's page doesn't give a status for that cloud.

A feature missing from this page tells you nothing about whether it works. fairfax only knows what is in its dataset.
